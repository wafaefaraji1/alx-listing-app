# ALX Listing App

A modern Airbnb clone built with Next.js, TypeScript, and TailwindCSS. This project serves as the foundation for building a dynamic, responsive, and user-friendly property listing application.

## Project Overview

The ALX Listing App aims to create a scalable and maintainable property listing platform similar to Airbnb. This initial milestone focuses on setting up the project structure, reusable components, and essential configurations.

## Features

- ✅ Next.js 13+ with TypeScript
- ✅ TailwindCSS for styling
- ✅ ESLint for code quality
- ✅ Reusable components (Card, Button)
- ✅ Type-safe interfaces
- ✅ Responsive design
- ✅ Clean project structure
